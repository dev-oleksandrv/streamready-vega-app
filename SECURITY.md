# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's
**Security → Report a vulnerability** (private vulnerability reporting) on this repository.
Do not open a public issue.

Include steps to reproduce, affected version, and impact. You will get an
acknowledgement within 7 days.

## Scope

StreamReady ships no backend and stores only the privacy-consent choice on the device.
Reports about M-Lab or geo-IP providers should go to those projects directly.
